# JLPT Official Practice Workbook Vol. 2 (2018) – N5

Content from the official *Japanese-Language Proficiency Test Official Practice Workbook Vol. 2* (published 2018, Bonjinsha), distributed free by the Japan Foundation / JEES on [jlpt.jp](https://www.jlpt.jp/e/samples/sampleindex.html).

The official workbooks contain almost the same number of questions as an actual test, with questions selected from among those used in real tests since the 2010 revision. They are the single most authoritative N5 practice resource.
